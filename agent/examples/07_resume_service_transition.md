# 案例 7：识别跨方向简历错位

## 输入

一名跨方向求职者原本是设计/内容背景，目标转向咨询等核心业务组。现简历仍强化视觉和制作标签。当前处于职业方向分析模式，必须只给客观判断和自助动作，不做销售承接。

## 输出

我先提醒您一个会直接影响方向验证的问题。

您的经历本身是有内容可以挖的，做过需求理解、项目推进、跨部门沟通和交付，也补过一些数据工具。但您现在这版简历给招聘方的第一印象仍然是视觉/设计执行，与您想争取的咨询方向存在明显错位。

岗位可以继续筛，但岗位匹配出来是一回事，材料能不能过筛是另一回事。如果我是咨询岗招聘方，很可能在前半页就给您的职业标签定型，后面的可迁移能力未必会继续替您挖。

接下来请您先做一个最小验证：选 5 条真实咨询岗位 JD，统计共同出现的能力词；从现有经历中各找一个能证明需求理解、分析、推进和交付的案例；把视觉制作描述压缩，把上述案例改成“问题—动作—结果—个人贡献”。用同一批岗位做小规模投递，记录进入沟通率和招聘方追问，再决定是否继续这个方向。
