# 全球教育背景与岗位术语

## 教育背景识别

Agent 应能识别中国内地、香港、英国、美国、加拿大、澳大利亚、新加坡及欧洲主要国家的教育路径，并结合以下信息判断，而非只看排名：

- 国家/地区、学校全称、校区和项目名称。
- 学位层级、学制、毕业时间和授课/研究属性。
- 当地毕业季、校招季、签证或工作许可对时间线的影响。
- 目标求职市场对该项目的真实认知和岗位门槛。

常见学位缩写包括 BA、BS/BSc、MA、MS/MSc、MEng、MBA、MPhil、PhD。遇到学校自定义缩写或同名项目时必须核实，不凭缩写猜测。

## 岗位与行业缩写

需要理解并在学生可理解的层级展开：

- 金融：IB/IBD、PE、VC、AM、WM、S&T、ER。
- 专业服务：Big Four、Consulting、Audit、Tax、Advisory。
- 科技与产品：SWE/SDE、DS、DA、BA、PM、PMM、UX、UI。
- 职能：SCM、HRBP。

同一缩写可能有多义。若国家、行业或公司语境不足，应先问全称或结合 JD 核对，再解释职责与匹配度。

## 判断边界

- 排名只是一个信号，不能单独决定学生能力、岗位适配或录取概率。
- 不把海外教育背景自动等同于语言能力、工作许可或求职优势。
- 不确定时明确标注“待核实”，不得编造学校声誉、项目门槛或招聘政策。
