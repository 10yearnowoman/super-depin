# 学生类型判断

## 核心维度

| 维度 | 常见取值 | 影响 |
|---|---|---|
| 学业/就业状态 | 在读、应届、待业、离职、在职转岗 | 决定窗口期、空档解释和服务节奏 |
| 教育体系 | 内地、香港、英国、美国、加拿大、澳大利亚、新加坡、欧洲主要国家 | 决定学位解释、毕业季、招聘季和材料口径 |
| 学位/项目 | BA、BS/BSc、MA、MS/MSc、MEng、MBA、MPhil、PhD 等 | 先核实项目全称和性质，不凭缩写或排名推断 |
| 目标市场 | 求职国家/地区、工作许可、当地招聘窗口 | 决定岗位门槛、时间和信息核验范围 |
| 投递反馈 | 未投、无面试、有面试无后续、有 Offer | 区分启动、简历、匹配、面试或决策问题 |
| 方向清晰度 | 单一明确、多方向并列、完全不确定 | 决定先改简历还是先做规划 |
| 证据完整度 | 有可验证结果、有素材无整理、无证据 | 决定简历和作品集策略 |
| 地区边界 | 单一城市、可异地、只接受线上/线下 | 决定岗位数量、流程和成本 |
| 服务适配 | 核心客群、边缘客群、明显不适配 | 决定是否继续承接 |

## 典型类型

### 未启动型

特征：几乎没有真实投递。  
策略：先形成最小可投版本并获取市场反馈，不把问题预设为背景或市场。

### 材料前端型

特征：投递较多但几乎没有面试。  
策略：检查目标岗位、简历定位、关键词、作品入口和目标层级。

### 面试转化型

特征：能进面试但无后续。  
策略：复盘案例表达、个人贡献、岗位理解、数据可信度和动机。

### 决策型

特征：有多个 Offer 或职业路径难以取舍。  
策略：比较职业资产、合同、收入、工时、能力积累、身体承受、退出条件和下一跳。

### 跨方向型

特征：原经历与目标岗位标签差异大。  
策略：先做能力翻译和岗位拆分，再决定简历版本，不直接承诺机会。

### 非核心人群

特征：年龄、状态或需求超出历史核心客群。  
策略：不直接拒绝或强行套用学生模板；先确认服务能否真实满足城市、岗位和流程要求。

## 海外背景核验

- 学校、校区、专业或学位简称不确定时，标记待核实并询问全称、国家/地区和毕业时间。
- 同一岗位简称在不同国家或行业含义不同时，结合目标市场和 JD 判断。
- 大学排名不能单独决定学生竞争力；还需结合课程、项目、经历、语言、工作许可和岗位证据。
