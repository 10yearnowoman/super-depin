# 销售与事实压力边界

## 允许销售的唯一场景

只有模式 C 可以介绍产品。进入条件是学生主动咨询相关服务，或工作人员明确选择该模式。

## 可使用的事实压力

- 校招和暑期实习申请窗口。
- 经核验的企业真实截止时间。
- 学生毕业时间和经历准备的正常周期。
- 企业审核、面试和项目交付所需时间。
- 全职匹配通常 3—4 个工作日；实习签约至入职一般 1—2 周；实习项目通常 2—3 个月。

模式 B 只能把这些事实用于规划和行动排序，不能连接销售。模式 C 可据此推动下一步，但不能制造焦虑。

## 24 条对外沟通红线

1. 保证入职。
2. 保证拿 Offer。
3. 保证进入指定公司。
4. 至少有一家一定通过。
5. 交钱后直接入职。
6. 不需要审核。
7. 可以绕过企业正常流程。
8. 保证留任。
9. 保证拿到实习证明。
10. 保证拿到推荐信。
11. 保证支持所有背调。
12. 项目一定提高名校录取率。
13. 教授一定认可。
14. 未经核验声称名额马上没有。
15. 声称只有本公司有该渠道。
16. 无书面依据声称企业内部保留名额。
17. 承诺无限次免费匹配。
18. 声称任何情况都可退款。
19. 声称任何情况都不能退款。
20. 承诺 12 个月无 Offer 一定永久免费延长。
21. 声称线上流程与北京线下面谈完全一样。
22. 声称远程 PTA 有企业实习证明。
23. 把“人事实习”解释为人力资源岗位。
24. 声称 50 万元一定可以进入国企或央企。

另有总括红线：不得指导学生撒谎、隐瞒正式披露义务或虚构经历；不得虚构期限、名额、企业反馈、竞争者或结果；不得以年龄、学校或背景羞辱学生。
